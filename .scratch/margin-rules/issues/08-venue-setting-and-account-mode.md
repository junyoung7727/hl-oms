# 08: Venue setting and account mode holds

**What to build:** With a margin policy configured, an instrument whose venue setting (isolated mode, venue leverage 2) is unknown in this link session or differs from the policy refuses plain orders on that instrument only. An account whose mode is unknown, is unified or portfolio, or is not on the allow-list refuses plain orders on the whole account. Reduce-only orders pass both holds. The node asks the venue for the settings at link-up and every 60 seconds for instruments without a position; the simulated venue answers and has controls for both; the status shows them. The OMS never changes a venue setting. Scenario rows: S17, S18. Claims: V-MARGIN-9, V-MARGIN-1.

  - Built, core: inputs `VenueSetting { session, instrument, isolated, leverage }` and `AccountMode { session, mode }`; events `venue_setting_noted`, `account_mode_noted`; holds `VenueSetting(instrument)` and `AccountMode`, both in the right column of the hold table. The settings and the mode live in the margin state and are emptied by every link change. The positions of a recorded margin report set the setting of their instruments without an extra event (the report is the record). The hold query lists one `VenueSetting` hold per configured instrument that is unknown or differs; the new-order check counts only the one of the order's instrument. `unifiedAccount` and `portfolioMargin` never pass; any other mode passes only when `account_modes_allowed` lists it.
  - Built, node: queries `VenueSetting { instrument }` and `AccountMode`. The reconciler asks, once per second, for what the core does not know in the current link session (this is the link-up query), and asks again every `runtime.venue_setting_poll_ms` (default 60 000, zero refused) for the setting of every instrument without a position. The account mode is asked once per link session. Simulated venue: answers both (default isolated / 2 and mode `standard`), controls `venue_setting` and `account_mode`, query counters in the dump. Status: `core.margin.venue_settings` and `core.margin.account_mode`. The Hyperliquid gateway does not answer either query yet (ticket 09). No gateway request changes a setting.
